<doge-form-email> web component

Purpose

An email-specific implementation of the doge-form component that sends form submissions via email.

Examples

Usage

1. Add the script to your webpage. 


          <script
            type="module"
            src="https://fetch.dogecoin.org/doge-form-email.js">
          </script>

2. Place a doge-form-email element on your page with your desired configuration. 


          <doge-form-email
            title="Contact Us"
            subtitle="We'd love to hear from you!"
            email-to="contact@example.com"
            email-subject="New Contact Form Submission"
            width="600px"
            submitButtonText="Send Message"
            questions='[
              {
                "title": "What\'s your name?",
                "subtitle": "Please enter your full name",
                "placeholder": "John Doe"
              },
              {
                "title": "What\'s your message?",
                "subtitle": "Tell us what\'s on your mind",
                "placeholder": "Your message here..."
              }
            ]'
          ></doge-form-email>

3. Handle form submissions using the 'doge-form-submit' event (optional). 


          const form = document.querySelector('doge-form-email');
          form.addEventListener('doge-form-submit', (e) => {
            console.log('Form responses:', e.detail.responses);
            console.log('Email body:', e.detail.emailBody);
          });

Properties

This component extends doge-form and adds the following properties:

Name Description
email-to Email address where the form responses will be sent
email-subject Subject line for the email (defaults to "Form Submission")
submitButtonText Text to display on the submit button (defaults to "Submit via email")

For all other properties and styling options, please refer to the base doge-form component documentation.

Slots

Name Description
submit-button Custom submit button slot. When using this slot, make sure to add type="submit" and onclick="this.closest('doge-form-email').shadowRoot.querySelector('form').requestSubmit()" to your button for proper form submission handling.

Events

Event Detail Description
doge-form-submit { responses: string[], emailBody: string } Dispatched when the form is submitted, containing the formatted responses and email body
