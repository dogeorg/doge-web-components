<doge-form> web component

Purpose

A flexible form component that collects responses to questions and sends them via email. Perfect for feedback forms, surveys, and contact forms.

Examples

Usage

1. Add the script to your webpage. 


          <script
            type="module"
            src="https://fetch.dogecoin.org/doge-form.js">
          </script>

2. Place a doge-form element on your page with your desired configuration. 


          <doge-form
            title="My Form"
            subtitle="Optional subtitle"
            question1="First question?"
            question1Subtitle="Optional subtitle for first question"
            question1Placeholder="Optional placeholder text"
            question2="Second question?"
            question2Subtitle="Optional subtitle for second question"
            question2Placeholder="Optional placeholder text"
            question3="Third question?"
            question3Subtitle="Optional subtitle for third question"
            question3Placeholder="Optional placeholder text"
            question4="Fourth question?"
            question4Subtitle="Optional subtitle for fourth question"
            question4Placeholder="Optional placeholder text"
            question5="Fifth question?"
            question5Subtitle="Optional subtitle for fifth question"
            question5Placeholder="Optional placeholder text"
            emailTo="recipient@example.com"
            emailSubject="Form Submission"
            width="600px"
          ></doge-form>

3. Handle form submissions using the 'doge-form-submit' event (optional). 


          const form = document.querySelector('doge-form');
          form.addEventListener('doge-form-submit', (e) => {
            console.log('Form responses:', e.detail.responses);
            console.log('Email body:', e.detail.emailBody);
          });

Properties

Name Description
title Form title displayed at the top
subtitle Optional subtitle displayed below the title
question1 to question5 Up to 5 optional questions to display in the form
question1Subtitle to question5Subtitle Optional subtitle text displayed below each question
question1Placeholder to question5Placeholder Optional placeholder text for each question's text area
emailTo Email address where the form responses will be sent
emailSubject Subject line for the email (defaults to "Form Submission")
width Width of the form (defaults to "100%")
height Height of the form (defaults to "auto")

Styling

Name Description
--doge-primary-color Primary color for buttons and interactive elements
--doge-primary-hover-color Hover color for buttons and interactive elements
--doge-text-color Text color for headings and form elements
--doge-text-color-secondary Text color for subtitle and secondary text
--doge-textarea-border-color Border color for text areas
--doge-textarea-background Background color for text areas
--doge-button-text-color Text color for buttons
--doge-textentry-text-color Text color for text entry fields
--doge-textentry-placeholder-text-color Text color for placeholder text in text entry fields
--form-width Width of the form container (defaults to "100%")
--form-height Height of the form container (defaults to "auto")
--form-background Background color of the form
--form-radius Border radius of the form container

Events

Name Description
doge-form-submit Fired when the form is submitted. The event detail contains the responses and email body.
